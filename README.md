# VALK — Jonatas Valcácio

Portfólio em HTML/CSS/JS puro (sem build), com visual *liquid glass*, galeria 3D circular de projetos (clique e arraste) e páginas de case em modal.

- `index.html` — estrutura
- `css/style.css` — visual, paleta e animações
- `js/app.js` — dados dos projetos, galeria 3D, modal, interações
- `assets/` — imagens, fonte Demo e favicon

Para rodar localmente: `python3 -m http.server` e abra http://localhost:8000.
